# Trainee Registration & Management System (CRUD + Authentication)

Isang full-stack web application na binuo gamit ang **HTML5**, **CSS3**, **JavaScript**, **PHP**, at **MySQL (XAMPP)**.

## Mga Features ng System:
* **User Authentication & Security:** Pagre-register ng account na may password encryption (`password_hash`), secure login gamit ang PHP Sessions, at logout function.
* **Create:** Pagdaragdag ng bagong trainee record sa MySQL database.
* **Read:** Real-time na pagpapakita ng listahan ng mga naka-register na trainees.
* **Update:** Pag-edit at pag-save ng pagbabago sa detalye ng trainee.
* **Delete:** Pagbura ng record na may JavaScript confirmation prompt.

## Mga Ginamit na Teknolohiya:
* **Front-End:** HTML, CSS, JavaScript
* **Back-End:** PHP
* **Database:** MySQL (phpMyAdmin / XAMPP)
